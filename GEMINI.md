# Token-efficient working rules

- Start with the files and symbols relevant to the task.
- Search before reading; never scan the entire repository without reason.
- Do not load dependencies, generated files, binaries, archives or build outputs.
- Read only relevant file sections.
- Summarize terminal output; show important errors and results only.
- Avoid repeating unchanged code or entire files.
- Return focused diffs rather than complete file replacements.
- Run targeted tests before broad test suites.
- Keep persistent instructions short.
- Load specialized workflows only when the task requires them.
- Never sacrifice correctness to save tokens.
